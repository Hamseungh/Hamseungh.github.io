# Dun Story Editor Mobile v1.0

PC Dun Story Editor v1.6.13의 JSON 저장 구조를 확인해 만든 모바일용 웹 에디터입니다.

## 사용
1. `index.html`을 브라우저에서 열어 기본 동작을 확인합니다.
2. PC에서 내보낸 JSON을 불러오고 스토리·장면·선택지를 편집합니다.
3. 'JSON 내보내기'를 눌러 저장한 파일을 PC 에디터에서 불러옵니다.

## 모바일 설치 및 오프라인
홈 화면에 추가하는 PWA로 사용하려면 이 폴더를 HTTPS 정적 웹 호스팅에 올려야 합니다. 로컬 파일로 열면 서비스 워커 및 PWA 설치가 지원되지 않을 수 있습니다.
브라우저 임시 저장은 기기/브라우저 데이터를 지우면 소실됩니다. JSON 내보내기로 별도 백업하세요.

## 주의
- 조건·효과·아이템·레시피 및 알 수 없는 최상위 필드와 행의 추가 필드는 보존합니다.
- 장면/선택지를 삭제하면 해당 선택지에 연결된 조건·효과도 삭제됩니다.
- PC에서 동시에 편집한 내용과 자동 병합되지 않습니다.
- JSON 파일을 열고 저장하는 기본 구조만 구현했으며, 실제 iOS/Android 및 PC 상호 호환 실기기 테스트는 아직 수행하지 않았습니다.

## v1.0.1 
- 장면 ID와 선택지 ID를 직접 수정할 수 있습니다. 입력창에서 포커스를 이동하면 적용됩니다.
- 빈 ID 및 동일 시트 내 중복 ID는 거부합니다.
- 장면 ID 변경 시 장면 이동 참조와 해당 장면의 선택지 소속 ID를 함께 수정합니다.
- 선택지 ID 변경 시 Conditions/Effects의 choice_id 참조를 함께 수정합니다.
- JSON 파일을 내보내기 전 검증 및 백업을 권장합니다.

## v1.0.2
- 스토리/장면 아래 선택지 빠른 이동 드롭다운 (내용 + ID)
- 선택지 선택 시 해당 편집 카드로 이동
- 미리보기에서 선택지를 눌러 다음 장면으로 이동
- 확률 분기: 0%/100%는 해당 결과로 이동, 그 외에는 성공/실패 경로를 직접 선택 (실제 확률 판정 아님)
- 선택지가 없는 자동 이동 장면은 '다음 장면으로 이동' 버튼 제공
- GitHub Pages에 올릴 때 sw.js의 캐시 버전을 변경하여 이전 앱 캐시를 갱신
